FORESEA STARLINK AGENT v0.8 - WINDOWS
====================================

REQUISITOS
- Windows Server 2019/2022/2025 ou Windows 10/11 x64
- Python 3.11 ou superior x64 no PATH
- Internet para compass.speedcast.com e, se e-mail estiver habilitado, Microsoft Graph
- PowerShell 5.1+
- Recomendado: 2 vCPU, 4 GB RAM e 20 GB livres

INSTALACAO
1. Extraia em C:\Automacao\StarlinkAgent.
2. Abra PowerShell como Administrador.
3. cd C:\Automacao\StarlinkAgent
4. Set-ExecutionPolicy -Scope Process Bypass
5. .\install-windows.ps1
6. Edite config.json e ajuste principalmente projection.cycle_start_day.
7. Coloque o logo em assets\logo.png (opcional).
8. Grave credenciais:
   .\.venv\Scripts\python.exe credential_setup.py
9. Teste login + CSV:
   .\.venv\Scripts\python.exe bootstrap_login.py
10. Teste o agente completo:
   .\.venv\Scripts\python.exe agent.py
11. Crie a tarefa diaria:
   .\create_task.ps1 -DailyTime "06:00"
12. Dashboard manual:
   .\start_dashboard.ps1
   Abrir http://127.0.0.1:8787
13. Dashboard no boot:
   .\create_dashboard_task.ps1

IMPORTANTE
A tarefa diaria deve usar o mesmo usuario Windows que executou credential_setup.py,
pois as credenciais do Compass ficam no Windows Credential Manager daquele usuario.
Preserve database\starlink.db durante upgrades.
Nao compartilhe data\compass_state.json.
