CHANGELOG

v0.8
----
- Periodo Compass estruturado: period_start, period_end e period_days.
- Deteccao do periodo pelo campo da pagina ou pelo nome do CSV.
- Historico usa period_end como data efetiva; collected_at permanece como trilha de auditoria.
- Fallback de previsao por MEDIA DO PERIODO COMPASS quando nao ha historico suficiente.
- source_file e SHA256 do CSV armazenados para auditoria.
- snapshot_key e indice unico para evitar insercao duplicada do mesmo snapshot.
- Classificacao de atualidade dos dados e idade em dias.
- Confianca da previsao BAIXA/MEDIA/ALTA.
- importar_snapshot.py para bootstrap de CSVs historicos.
- Dashboard mostra periodo, atualidade, idade e confianca.
- Excel recebeu colunas de auditoria e qualidade dos dados.
- PDF/e-mail identificados como v0.8.

v0.7
----
- Dashboard web local lendo o mesmo SQLite do agente.

- Deteccao de reinicio/queda do acumulado para evitar projecoes incorretas na virada de ciclo.

- Calculo de dias ate 100% e data prevista para atingir a franquia.
- Projecao de consumo e overage no fim do ciclo.
- Risco projetado: CONTROLADO, RISCO MODERADO, RISCO ALTO, ESTOURO PREVISTO ou ESTOURADO.
- PDF executivo ampliado para tres paginas: situacao atual, tendencia/previsao e detalhamento tecnico.

v0.8.1 Linux Adaptive
- Instalador detecta /etc/os-release, VERSION_ID, arquitetura e versao real do Python.
- Ubuntu 20.04 e Debian 11 usam perfil legacy (Playwright 1.48 / pandas 2.0.3) compativel com Python 3.8.
- Ubuntu 22.04/24.04 e Debian 12 usam perfil modern quando Python >=3.9.
- Fallback seguro para outras versoes Ubuntu/Debian com selecao por versao do Python.
- Verificacao de Python minimo 3.8 antes da instalacao.
- Virtualenv e recriado automaticamente quando usa versao de Python diferente da atual.
- Instalacao valida imports Python e inicializacao real do Chromium headless.
- Perfil detectado salvo em runtime-profile.env para auditoria/suporte.
- Novo diagnostico-linux.sh para OS, Python, pacotes, Chromium e systemd.
