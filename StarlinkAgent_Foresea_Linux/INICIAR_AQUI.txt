FORESEA STARLINK AGENT v0.9.8 - LINUX
==================================
1. chmod +x install-linux.sh
2. sudo ./install-linux.sh
3. sudo nano /opt/starlink-agent/config.json
4. sudo /opt/starlink-agent/credential_setup.py
5. sudo /opt/starlink-agent/test-login-linux.sh
6. sudo systemctl start starlink-agent.service
7. sudo /opt/starlink-agent/enable-services-linux.sh
8. Dashboard: http://127.0.0.1:8787

Guia completo: LINUX_PASSO_A_PASSO.txt

IMPORTANTE - v0.9.3
O instalador Linux agora detecta automaticamente a versao do sistema operacional e do Python.
Em Ubuntu 20.04/Python 3.8, NAO e necessario editar requirements manualmente: o perfil legacy sera selecionado automaticamente.
Use: sudo ./install-linux.sh
Depois confira: sudo /opt/starlink-agent/diagnostico-linux.sh
