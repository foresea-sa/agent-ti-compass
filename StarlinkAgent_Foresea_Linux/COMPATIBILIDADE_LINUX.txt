STARLINK AGENT v0.8.1 - MATRIZ DE COMPATIBILIDADE LINUX
=======================================================

O install-linux.sh detecta automaticamente o sistema em /etc/os-release e o Python real.

PERFIL LEGACY
-------------
Usado automaticamente em:
- Ubuntu 20.04 LTS (Focal)
- Debian 11
- Ou fallback quando Python = 3.8

Dependencias principais:
- playwright 1.48.0
- pandas 2.0.3
- openpyxl 3.1.5
- reportlab 4.4.3
- requests 2.32.3
- msal 1.33.0

PERFIL MODERN
-------------
Usado automaticamente em:
- Ubuntu 22.04 LTS
- Ubuntu 24.04 LTS
- Debian 12
- desde que Python >= 3.9

Dependencias principais:
- playwright 1.55.0
- pandas 2.3.2
- openpyxl 3.1.5
- reportlab 4.4.3
- requests 2.32.5
- msal 1.33.0

REGRAS
------
- Python minimo: 3.8
- Somente Ubuntu/Debian com apt-get sao instalados automaticamente nesta versao.
- O instalador grava /opt/starlink-agent/runtime-profile.env com o perfil escolhido.
- Execute sudo /opt/starlink-agent/diagnostico-linux.sh para confirmar o ambiente.

EXEMPLO ESPERADO NO UBUNTU 20.04
--------------------------------
OS detectado: Ubuntu 20.04.x LTS
Python detectado: Python 3.8.x
Perfil selecionado: legacy
Requirements: requirements-linux-legacy.txt
